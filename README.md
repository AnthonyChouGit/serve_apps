# Proxy & Web Server Tutorials

Welcome to the comprehensive setup guide for deploying modern web and proxy services. This repository contains complete configurations and tutorials for various applications.

## Projects Available

- **[Nginx with Certbot](./nginx-with-certbot)**: An auto-renewing Nginx web server configured with Let's Encrypt certificates.
- **[Hysteria2](./proxy/hysteria2)**: A powerful, high-speed proxy server utilizing the Hysteria2 protocol with Salamander obfuscation.
- **[Sing-box Reality](./proxy/singbox-reality)**: A proxy setup focusing on stealth and stability using Sing-box's VLESS Reality implementation.
- **[Proxy Client Config](./proxy)**: A generic configuration setup for proxy clients.
- **[Postgres Dev Environment](./postgres-dev)**: A quick start Docker compose setup for PostgreSQL database development.
- **[Node Dev Environment](./node-dev)**: A development container setup for Node.js projects.
- **[SyncTV](./synctv)**: A synchronized video playback service for watching movies and videos together with friends.
- **[Hermes Agent](./hermes)**: An autonomous, self-improving AI agent gateway and runtime environment powered by Nous Research.
- **[OpenList Cloud Mount](./openlist-mount)**: A concise macOS guide and scripts for mounting cloud drives in Finder using OpenList, rclone, and FUSE-T.
- **[SFTP Remote Disk Mount](./sftp-mount)**: End-to-end guide for formatting a drive on a Linux server, exposing it via an Alpine SFTP container over EasyTier P2P, and mounting it on macOS with rclone.
- **[FRP Reverse Proxy](./frp)**: Docker Compose setup for frps (VPS server) and frpc (client) to expose internal services with minimal exposed ports.

Each folder contains its own `README.md` with detailed instructions on configuration and deployment. Choose the project you wish to deploy and follow its specific guide.
